Proses Instalasi

⏳Install npm dependencies (backend + frontend)
⏳Install PM2 (process manager, auto-start)
⏳Generate Prisma Client (ORM database)
⏳Simpan konfigurasi .env
⏳Migrasi & buat tabel database
⏳Isi data awal (akun admin default)
⏳Build frontend (Vue → static files)
⏳Start server dengan PM2
